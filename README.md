# Advanced Password Generator GUI

This project was developed for the Synent Technologies Python Programming Internship.

The application generates secure and random passwords using Python.  
It provides a professional graphical user interface (GUI) where users can customize password generation options according to their requirements.

## Features

- Professional GUI Interface using Tkinter
- Generate strong and secure passwords
- User can choose:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- Custom password length support
- Interactive and user-friendly design
- Random password generation for better security

## Technologies Used

- Python
- Tkinter
- random module
- string module
- VS Code

## How to Run the Project

1. Open the project folder in VS Code
2. Open terminal
3. Run the following command:

python main.py

4. The GUI window will open
5. Select password options
6. Click on "Generate Password"

## Project Objective

The main objective of this project is to create a secure password generator application with a graphical user interface that helps users generate strong passwords easily.

## Output

The application generates strong random passwords based on the selected options.
